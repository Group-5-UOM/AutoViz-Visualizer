## Overview

The schedule covers a **14-week development period** organized around the traditional SDLC (requirements analysis, system design, implementation, integration, testing, deployment). It is **not strict Waterfall** — related activities overlap, and testing and documentation continue throughout. Progress is reviewed weekly, with task completion percentages updated in GanttProject.

## Timeline / Phases

| Weeks | Phase | Key Activities |
|---|---|---|
| **1–2** | Initiation | Clarify the project idea, meet the mentor, prepare the project proposal. |
| **3–4** | Requirements & Design | Requirements analysis and system design. **Week 4 deliverables:** feasibility document, Gantt chart, Software Requirements Specification (SRS), architecture & design document, second mentor meeting. |
| **4–7** | Development Iteration 1 | Next.js + FastAPI application structure, CSV upload, data profiling, controlled data operations, MCP tools, structured analysis-plan generation, Vega-Lite visualization, dashboard implementation. **Target: working end-to-end MVP (~85% of scope) before the Week 8 mid-evaluation.** |
| **8–11** | Development Iteration 2 & System Testing | Refine dashboard interactions, strengthen validation & security, improve reliability, run usability & correctness evaluations, prepare the Testing & Evaluation Document. |
| **12–14** | Finalization | Final defect correction, deployment, documentation, demonstration preparation, final evaluation, and submission. |

## Milestones

- **Week 4** — Requirements & design documents complete (feasibility, Gantt, SRS, architecture/design).
- **Week 8** — Mid-evaluation; end-to-end MVP (~85% of scope) ready.
- **Week 11** — Testing & Evaluation Document prepared.
- **Week 14** — Final evaluation and submission.
